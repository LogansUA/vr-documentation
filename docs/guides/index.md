# Гайди

Цей розділ призначений для пояснення проходження босів та рейдових механік.

## Що має бути в цьому розділі

1. Тактики на босів
2. Пояснення рейдових обов'язків для кожної ролі
3. Особливості виконання механік у форматі гільдії
4. Відео, приклади позиціонування та корисні посилання

## Формат гайдів

Щоб розділ було легко підтримувати, кожен гайд має відповідати на практичні питання:

1. Що потрібно підготувати перед рейдом?
2. Яка основна задача гравця?
3. Які механіки або помилки найчастіше призводять до вайпу?
4. Які дії очікуються від конкретної ролі?
