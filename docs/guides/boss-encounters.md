# Боси

Ця сторінка є основою для опису тактик на босів та пояснення рейдових механік.

## Структура гайду по босу

Для кожного боса варто використовувати однакову структуру:

1. **Короткий опис** - що є головною ідеєю бою
2. **Склад рейду** - рекомендована кількість танків, хілів, рдд та мдд
3. **Позиціонування** - де стоять танки, хіли, рдд та мдд
4. **Фази бою** - що змінюється протягом енкаунтеру
5. **Обов'язки ролей** - окремо для танків, хілів, рдд та мдд
6. **Небезпечні механіки** - що не можна ігнорувати
7. **Типові причини вайпів** - найчастіші помилки рейду
8. **Особливості гільдії** - як саме цей бій проходить Verkhovna Rada
